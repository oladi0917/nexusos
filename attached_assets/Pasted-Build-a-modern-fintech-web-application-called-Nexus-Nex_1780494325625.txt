Build a modern fintech web application called Nexus.

Nexus is a financial management platform that allows users to view multiple bank accounts in one dashboard, see combined balances, track transactions, and send money. For this MVP, use realistic demo data and simulated banking functionality. The architecture should be structured so real integrations with Mono/Okra and Paystack can be added later.
